# Convex separation roadmap

The goal is a small Lean development of a separation theorem for convex sets.
The roadmap records mathematical direction; theorem-sized dependencies live in
the [node graph](../README.md#formalization-nodes).

## Current state

The basic convexity vocabulary is available. The supporting-hyperplane lemma is
ready for formalization, after which the final separation theorem can begin.

## Milestones

1. Reuse or formalize the required definition of a convex set.
2. Prove the supporting-hyperplane lemma.
3. Prove the separation theorem.
