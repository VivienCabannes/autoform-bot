# Parity note roadmap

The fictional source has three areas:

1. **Parity core**: the definition of evenness, addition, scaling, and linear
   combinations. This is the current detailed milestone.
2. **Divisibility extensions**: mapped for later source audit, with no theorem
   nodes yet.
3. **Congruence examples**: excluded from the current formalization target.

The roadmap is deliberately broader than `graph.json`. Mapping an area does not
claim that its statements have been inspected or decomposed.
