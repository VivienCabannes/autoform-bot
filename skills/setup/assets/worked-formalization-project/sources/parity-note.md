# A short note on parity

This fictional note exists only to demonstrate source anchoring.

## Parity core

The selected milestone consists of the following two definitions and three
closure results.

### `parity:def:even`

An integer is even when it is twice another integer.

### `parity:def:linear-combination`

For integers `a`, `b`, `x`, and `y`, their linear combination is
`a * x + b * y`.

### `parity:thm:add`

The sum of two even integers is even.

### `parity:thm:scale`

An integer multiple of an even integer is even.

### `parity:thm:linear-combination`

Every integer linear combination of two even integers is even.
