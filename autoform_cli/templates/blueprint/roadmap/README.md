This page is the book's preface and table of contents. Keep it short: name the
goal, then link the chapters in reading order.

Each chapter is a directory holding a `README.md`. That `README.md` *is* the
chapter: it carries the narrative prose, and the formalizable statements below
it are placed into that prose where they are first used.

    roadmap/
      README.md              <- you are here
      first-chapter/
        README.md            <- the chapter, with its exposition
        some-definition.md   <- a formalizable leaf
        main-result.md

A chapter directory without a `README.md` is not a chapter; its pages collapse
to the top level and the published book has no structure. Run `autoform check`
after adding one.
